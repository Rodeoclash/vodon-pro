# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/Rodeoclash/vodon-pro/security/advisories/new),
not in a public issue or pull request.

Include the version of Vodon Pro, your operating system, and the steps to
reproduce the issue. You'll get a reply once the report has been looked at;
this is a one-person project, so please allow some time.

## Supported versions

Only the latest release gets security fixes. Vodon Pro updates itself from
[GitHub Releases](https://github.com/Rodeoclash/vodon-pro/releases), and
each release's files carry provenance and SBOM attestations you can check
with `gh attestation verify <file> --repo Rodeoclash/vodon-pro`.
